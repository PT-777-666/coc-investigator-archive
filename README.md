# 探索者アーカイブ

クトゥルフ神話TRPG(CoC)の探索者(キャラクター)データを、外部のキャラクターシートサービスに
依存せずローカルに保管・検索・更新するための個人用Webアプリです。
Node.js等のビルドツールを使わない素のHTML/CSS/JavaScriptで作られています。

## 特徴

- 探索者の登録・一覧・詳細表示・編集・削除
- 名前・職業・タグ・技能名などでのフリーワード検索、システム/状態での絞り込み、タグ絞り込み(AND)
- 名前・職業・システム・能力値(各値/合計)・作成日・更新日での並べ替え
- **探索者ごとに1つのJSONファイルとして、自分で選んだローカルフォルダに直接保存**(File System
  Access API)。ブラウザのサイトデータを消してもファイルは無事です。フォルダを丸ごとコピーするだけで
  バックアップになります
- JSONエクスポート/インポートで、全件まとめたバックアップ・復元も可能(画像もbase64で同梱)
- PWA対応。Edge/Chromeでインストールすると、ブラウザのタブではなく独立したアプリのウィンドウとして
  起動できます

## 動作環境

**Microsoft Edge または Google Chrome**が必要です(データ保存にFile System Access APIという
Chromium系ブラウザ専用の機能を使っているため、Firefox等では動作しません)。

## ローカルでの起動方法

`index.html` を直接ダブルクリックすると正しく動作しないため、同梱のPowerShellサーバーを
経由して開いてください。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\static-server.ps1
```

起動したら `http://localhost:28740/` をEdgeかChromeで開いてください。
`tools\start-app.ps1` をダブルクリックすると、サーバー起動とブラウザでの表示を一度に行えます。

### アプリとしてインストールする(任意)

上記URLをEdge/Chromeで開いた状態で、アドレスバーの「インストール」アイコン
(Chromeは⊕マーク、Edgeはアプリアイコン)をクリックすると、ブラウザのタブではなく
独立したウィンドウのアプリとしてスタートメニューなどから起動できるようになります。
インストールしなくても、ブラウザのタブとして開くだけで全ての機能が使えます。

## データの保存場所と注意点

- 初回起動時に、探索者データの保存先フォルダを選びます(OneDriveなどの同期フォルダの中でもOKです)。
- 探索者ごとに `名前_id.json` というファイルが、選んだフォルダに直接作られます。**このフォルダの
  中身そのものがデータの実体**なので、フォルダを普段お使いのバックアップ手段(クラウド同期・
  外部ドライブへのコピー等)で保護してください。
- ブラウザ側(IndexedDB)に保存しているのは「どのフォルダを選んだか」という情報だけです。
  ブラウザのサイトデータを消しても、フォルダ内のファイルは影響を受けません
  (再度フォルダへのアクセスを許可し直すだけで、そのまま使えます)。
- ヘッダーの「保存先を変更」から、いつでも別のフォルダに切り替えられます。
- 常に同じURL(ポート番号)からアクセスしてください。ポートを変えると、フォルダの選択情報を
  覚えている場所(ブラウザのオリジン)が変わってしまいます。
